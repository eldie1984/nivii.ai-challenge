  Development Commands                                                                                                                                                     
                                                                                                                                                                           
  # Build the project                                                                                                                                                      
  docker-compose build                                                                                                                                                     
                                                                                                                                                                           
  # Run database migrations                                                                                                                                                
  docker-compose run --rm database python manage.py migrate                                                                                                                
                                                                                                                                                                           
  # Run tests (unit + integration)                                                                                                                                         
  docker-compose run --rm python manage.py test                                                                                                                            
                                                                                                                                                                           
  Developer Setup                                                                                                                                                          
                                                                                                                                                                           
  Environment                                                                                                                                                              
                                                            
  # Initialize local environment                                                                                                                                           
  cp .env.example .env                                                                                                                                                     
  # Edit .env with project-specific credentials                                                                                                                            
                                                                                                                                                                           
  # Install dependencies                                                                                                                                                   
  docker-compose run --rm node npm install                                                                                                                                 
                                                                                                                                                                           
  Services Architecture                                                                                                                                                    
                                                                                                                                                                           
  ├─ services                                                                                                                                                              
  │  ├─ api-gateway/     → Central routing/auth (port 3001)                                                                                                                
  │  ├─ portfolio/       → Securities management (POSTGRESQL 5432)                                                                                                         
  │  ├─ transaction/     → Trading execution (REDIS 6379)                                                                                                                  
  │  └─ agent-orchestrator/ → AI decision engine (integrates with all services)                                                                                            
                                                                                                                                                                           
  Key Tools                                                                                                                                                                
                                                                                                                                                                           
  - PostgreSQL: Multi-schema database with per-service isolation                                                                                                           
  - Redis: Message queue for real-time transaction processing
  - Docker: Container orchestration with environment-specific configurations                                                                                               
  - AI Orchestration: Services communicate through defined API contracts                                                                                                   
                                                                                                                                                                           
  Operational Procedures                                                                                                                                                   
                                                                                                                                                                           
  1. Production Start-up                                                                                                                                                   
  # Initialize production environment                       
  docker-compose up -d --build                                                                                                                                             
                                                                                                                                                                           
  2. Database Maintenance                                                                                                                                                  
  - Use docker-compose exec database python manage.py shell for schema queries                                                                                             
  - Never modify production database directly                                                                                                                              
                                                                                                                                                                           
  3. AI Integration                                                                                                                                                        
  - All services must implement AgentInterface for orchestration                                                                                                           
  - Orchestrator uses message broker patterns for async communication                                                                                                      
                                                                                                                                                                           
  Key Constraints                                                                                                                                                          
                                                                                                                                                                           
  - No API Key Hardcoding: All credentials must come from environment variables                                                                                            
  - No Direct DB Access: All database interactions go through service APIs                                                                                                 
  - No Legacy Features: Always implement new features through existing interfaces                                                                                          
                                                                                                                                                                           
  Deployment Notes                                                                                                                                                         
                                                                                                                                                                           
  - Frontend serves at port 3000 (React/TypeScript)                                                                                                                        
  - Use docker-compose up -d for production builds          
  - Monitor via Prometheus (available at :9090) and Grafana dashboards
